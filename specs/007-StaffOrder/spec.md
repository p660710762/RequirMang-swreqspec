# Feature: ดูรายการ Order สำหรับพนักงาน (Staff Order List)
Spec ID: SPEC-STAFF-ORDER-001 | Source: SRS v0.1 ข้อ 3.7 (FR-STAFF-ORDER) | Use case: UC-07  
Owner: <660710722> | Status: Draft v2 | Updated: 2569-09-18  
Depends on: SPEC-ORDER-001, SPEC-ORDER-STATUS-001 | Reviewed by: -

## Goal
พนักงานร้าน (Staff) สามารถดูรายการ Order ที่ลูกค้าสั่งเข้ามา
พร้อมหมายเลข Order ลำดับ Order รายละเอียดเครื่องดื่ม จำนวน ตัวเลือก
และสถานะปัจจุบันของแต่ละ Order เพื่อใช้ในการเตรียมเครื่องดื่มได้อย่างถูกต้อง

## Scope
### In scope
- ดูรายการ Order ที่ลูกค้าสั่งเข้ามา
- แสดงหมายเลข Order
- แสดงลำดับของ Order ตามเวลาที่สั่งเข้ามา
- แสดงรายละเอียดเครื่องดื่มในแต่ละ Order
- แสดงจำนวนเครื่องดื่ม
- แสดงตัวเลือกของเครื่องดื่ม
- แสดงสถานะปัจจุบันของ Order
- แสดง Order ที่มีสถานะต่าง ๆ ในรายการ และวาง Order ที่สิ้นสุดลงท้ายรายการ
- รองรับกรณีไม่มี Order ใหม่
- รองรับการโหลดรายการ Order ใหม่เมื่อเกิดข้อผิดพลาด
- รองรับการอัปเดตรายการ Order แบบ Real-time

### Out of scope
- การสร้าง Order
- การแก้ไขรายการสินค้าใน Order โดยพนักงาน
- การชำระเงิน
- การเปลี่ยนแปลงรายละเอียด Order โดยพนักงาน
- การจัดการเมนู ราคา และโปรโมชั่น
- การจัดการข้อมูลลูกค้า
- การส่งแจ้งเตือนผ่าน LINE
- การดูรายงานยอดขายและสถิติ

## Constraints
- ผู้ใช้งานต้องเข้าสู่ระบบและมีสิทธิ์เป็น Staff ก่อนเข้าถึงรายการ Order
- ระบบต้องแสดงเฉพาะ Order ที่พนักงานมีสิทธิ์เข้าถึง
- รายการ Order ต้องแสดงข้อมูลจากระบบที่เป็นข้อมูลล่าสุด
- รายละเอียดของ Order ต้องตรงกับรายการที่ลูกค้าสั่ง
- หากไม่สามารถโหลดข้อมูล Order ได้ ระบบต้องไม่แสดงข้อมูลที่ไม่สมบูรณ์หรือไม่ยืนยัน
- ลำดับของ Order คือ ลำดับตามเวลาที่สั่งเข้ามา
- Order ที่สถานะ “รับสินค้าแล้ว” หรือ “ยกเลิก” จะยังคงแสดงในรายการ แต่จะถูกวางไว้ท้ายรายการตามสถานะ
- ระบบต้องอัปเดตรายการ Order แบบ Real-time เมื่อมี Order ใหม่เข้ามา
- พนักงานสามารถดู Order ย้อนหลังได้ภายใน 7 วัน

## Requirements
- FR-29  
  พนักงานสามารถเปิดดูรายการ Order ที่ลูกค้าสั่งเข้ามาได้

- FR-30  
  ระบบต้องแสดงหมายเลข Order และลำดับของ Order เพื่อให้พนักงานสามารถระบุและจัดลำดับการเตรียมเครื่องดื่มได้
  ลำดับของ Order หมายถึง ลำดับตามเวลาที่สั่งเข้ามา

- FR-31  
  ระบบต้องแสดงรายละเอียดของ Order ได้แก่ รายการเครื่องดื่ม จำนวน และตัวเลือกที่ลูกค้าสั่ง

- FR-32  
  ระบบต้องแสดงสถานะปัจจุบันของแต่ละ Order ให้พนักงานทราบ
  Order ที่สถานะ “รับสินค้าแล้ว” หรือ “ยกเลิก” จะยังคงแสดงในรายการแต่จะถูกวางไว้ท้ายรายการตามสถานะ

- FR-33  
  ระบบต้องจัดเรียงรายการ Order ตามเวลาที่สั่งล่าสุดก่อน เพื่อให้พนักงานสามารถตรวจสอบและดำเนินการตามลำดับ Order ได้
  Order ที่สิ้นสุดจะถูกจัดไว้ท้ายรายการ

### Alternative Flow Requirement

- FR-29 / UC-07 Alternative Flow 2a  
  หากยังไม่มี Order ใหม่ ระบบต้องแสดงข้อความหรือสถานะที่ระบุว่าไม่มีรายการ Order ใหม่

### Exception Flow Requirement

- UC-07 Exception Flow 2b  
  หากระบบไม่สามารถโหลดรายการ Order ได้ ระบบต้องแจ้งให้พนักงานทราบว่าไม่สามารถโหลดรายการ Order ได้ และมีปุ่ม “ลองใหม่” เพื่อเรียกข้อมูลอีกครั้ง

## Quality Requirements
- NFR-22  
  หน้ารายการเมนูและหน้าตรวจสอบสถานะ Order ต้องตอบสนองภายใน 2 วินาที (p95) ภายใต้จำนวนผู้ใช้พร้อมกัน 100 concurrent users

- NFR-PERF-01  
  หน้ารายการ Order สำหรับพนักงานต้องสามารถแสดงรายการ Order และรายละเอียดที่เกี่ยวข้องภายในเวลาที่เหมาะสมต่อการปฏิบัติงาน

- NFR-USE-01  
  หมายเลข Order ลำดับ และสถานะของ Order ต้องแสดงอย่างชัดเจน เพื่อให้พนักงานสามารถระบุ Order และดำเนินการเตรียมเครื่องดื่มได้อย่างถูกต้อง

## Acceptance Criteria

- [ ] AC-STAFF-ORDER-01 (FR-29)

  Given มี Order อยู่ในระบบ  
  When พนักงานเปิดหน้ารายการ Order  
  Then ระบบแสดงรายการ Order ที่ลูกค้าสั่งเข้ามา

- [ ] AC-STAFF-ORDER-02 (FR-30)

  Given ระบบมีรายการ Order  
  When พนักงานเปิดหน้ารายการ Order  
  Then ระบบแสดงหมายเลข Order และลำดับของแต่ละ Order อย่างชัดเจน

- [ ] AC-STAFF-ORDER-03 (FR-31)

  Given พนักงานเลือกหรือเปิดดู Order  
  When ระบบโหลดรายละเอียด Order สำเร็จ  
  Then ระบบแสดงรายการเครื่องดื่ม จำนวน และตัวเลือกของเครื่องดื่มอย่างถูกต้อง

- [ ] AC-STAFF-ORDER-04 (FR-32)

  Given Order มีสถานะปัจจุบันอยู่ในระบบ  
  When พนักงานเปิดรายการ Order  
  Then ระบบแสดงสถานะปัจจุบันของแต่ละ Order

- [ ] AC-STAFF-ORDER-05 (FR-33)

  Given ระบบมี Order หลายรายการ  
  When พนักงานเปิดหน้ารายการ Order  
  Then ระบบแสดง Order ตามลำดับที่กำหนด เพื่อให้พนักงานสามารถตรวจสอบและดำเนินการตามลำดับได้

- [ ] AC-STAFF-ORDER-06 (UC-07 Alternative Flow 2a)

  Given ยังไม่มี Order ใหม่ในระบบ  
  When พนักงานเปิดหน้ารายการ Order  
  Then ระบบแสดงข้อความหรือสถานะว่าไม่มีรายการ Order ใหม่

- [ ] AC-STAFF-ORDER-07 (UC-07 Exception Flow 2b)

  Given พนักงานเปิดหน้ารายการ Order  
  When ระบบไม่สามารถโหลดข้อมูล Order ได้  
  Then ระบบแสดงข้อความว่าไม่สามารถโหลดรายการ Order ได้ และมีปุ่ม “ลองใหม่” เพื่อเรียกข้อมูลอีกครั้ง

- [ ] AC-STAFF-ORDER-08 (NFR-PERF-01)

  Given ระบบมีรายการ Order อยู่ในระบบ  
  When พนักงานเปิดหน้ารายการ Order  
  Then ระบบแสดงรายการ Order และข้อมูลที่จำเป็นภายในเวลาที่เหมาะสมต่อการปฏิบัติงาน

- [ ] AC-STAFF-ORDER-09 (NFR-USE-01)

  Given พนักงานเปิดหน้ารายการ Order  
  When ระบบแสดงข้อมูล Order  
  Then หมายเลข Order ลำดับ และสถานะของ Order ต้องสามารถมองเห็นและระบุได้อย่างชัดเจน

## Assumptions and Open Questions

### Assumptions
- ASM-01  
  ผู้ใช้งานที่เข้าหน้านี้เป็นพนักงานที่ผ่านการเข้าสู่ระบบและมีสิทธิ์เป็น Staff

- ASM-02  
  ระบบมีข้อมูล Order ที่ลูกค้าสร้างไว้แล้ว

- ASM-03  
  Order มีหมายเลขและลำดับที่สามารถใช้ระบุรายการได้

- ASM-04  
  รายละเอียด Order ประกอบด้วยรายการเครื่องดื่ม จำนวน และตัวเลือกของเครื่องดื่ม

- ASM-05  
  Order มีสถานะที่สามารถแสดงให้พนักงานตรวจสอบได้

- ASM-06  
  หากยังไม่มี Order ใหม่ ระบบจะแสดงข้อความหรือสถานะว่าไม่มีรายการ Order ใหม่

- ASM-07  
  หากโหลดรายการ Order ไม่สำเร็จ ระบบจะแสดงปุ่ม “ลองใหม่”

- ASM-08  
  รายการ Order ต้องอัปเดตแบบ Real-time เมื่อมี Order ใหม่เข้ามา

- ASM-09  
  พนักงานสามารถดู Order ย้อนหลังได้ภายใน 7 วัน

- ASM-10  
  Order ที่สถานะ “รับสินค้าแล้ว” หรือ “ยกเลิก” จะถูกแสดงต่อและจัดไว้ท้ายรายการตามสถานะ

### Open Questions
- หลังจาก Order สิ้นสุดแล้ว ควรมีการลบออกจากหน้ารายการหรือให้คงไว้และแสดงเป็นสถานะสุดท้ายต่อไป
- มีเงื่อนไขทางสิทธิ์หรือช่วงเวลาใดบ้างที่อนุญาตให้พนักงานเห็น Order เก่าเกิน 7 วัน
- ระบบควรมีการแจ้งเตือนหลังกดใหม่เข้ามาหรือใช้การแสดงรายการอัตโนมัติอย่างไร
