## วิธีเริ่ม

1. กด Code แล้วเลือก Codespaces สร้างเครื่องใหม่ (หรือ clone ลงเครื่องแล้วเปิดด้วย Cursor / Claude Code)
2. เปิด Copilot Chat สลับเป็นโหมด Agent
3. พิมพ์ `/clarify specs/001-booking/spec.md`
4. ตอบคำถาม แล้วดู diff ของ spec.md ก่อน commit

รายละเอียดคำสั่งอยู่ที่ `docs/agent-pack-README.md`

## ถ้าเป็น repo ของทีม

## Week 07 — สรุปผลการตรวจสอบ

1. จุดอ่อนของ Test เดิม: Test เดิมเช็กแค่ว่าหน้าเมนูแสดงถูกไหม ปุ่มกดได้หรือเปล่า แต่ยังไม่ได้เช็กว่าพอกดแล้วเกิดอะไรขึ้นจริง ๆ
2. บั๊กที่ Test ใหม่เจอ: ตอนที่ไม่มีเมนู ระบบขึ้นคำว่า "ไม่พบเมนู" ทั้งที่ Spec กำหนดให้ขึ้นว่า "ขณะนี้ไม่มีรายการเครื่องดื่ม" ซึ่งตอนนี้แก้แล้ว
3. สิ่งที่คนเจอแต่ AI ไม่เจอ: ทีมเจอว่าใน Spec มีบางส่วนเขียนขัดกัน เรื่องการแสดงเมนูที่ขายหมดตอนที่ไม่มีโปรโมชั่น เลยแก้ให้ตรงกัน
4. สิ่งที่ AI เข้าใจผิด: AI เสนอให้ทำระบบสั่งซื้อกับเพิ่มเครื่องมือทดสอบ ทั้งที่ระบบสั่งซื้อออนไลน์อยู่นอกขอบเขตงาน และ Task ส่วนนี้ยังไม่ได้ทำ
5. สิ่งที่ควรถามผู้ใช้: ถ้าลูกค้ากดปุ่มสั่งซื้อ แต่ระบบสั่งซื้อออนไลน์ยังไม่เปิดใช้งาน ควรให้หน้าเว็บแสดงข้อความว่าอะไร
